# CF-AI-Dashboard-MCP

Cloudflare Workers AI Dashboard with MCP support.

## Features

- Workers AI Analytics
- OpenAI Billing
- OpenRouter Billing
- Gemini Billing
- BigQuery Billing
- MCP Server
- Hermes Integration

- get_dashboard_stats

- get_openai_stats
- get_openai_debug

- get_openrouter_stats
- get_openrouter_debug

- get_anthropic_stats
- get_anthropic_debug

- get_gemini_stats
- get_gemini_debug

- get_groq_stats
- get_groq_debug

- get_workers_ai_stats

- get_models
- get_top_models

- get_providers
- get_health
